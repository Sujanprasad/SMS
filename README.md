# 🎓 Student Database Management System

## 📌 Abstract

The **Student Database Management System** is a full-stack web application developed using **Python Flask** and **SQLite** to efficiently manage student-related academic data.  
This project demonstrates core database concepts such as:

- CRUD Operations
- Relational Database Design
- Table Relationships
- SQL Joins

The system integrates three major modules:

- Students
- Courses
- Enrollments

The backend is developed using the **Flask Framework**, while **SQLite** is used for database management.  
The frontend is built with **HTML5, CSS3, and Bootstrap 5**, providing a responsive and user-friendly interface.

This project showcases the practical implementation of backend development, frontend integration, and relational database management within a single cohesive system.

# 📖 System Overview

The system consists of three major modules:

## 👨‍🎓 Students Module
Manages student-related information such as:

- Student ID
- Name
- Age
- Department

### Features
- Add Student
- View Students
- Update Student Details
- Delete Student Records

---

## 📚 Courses Module
Stores and manages course-related information including:

- Course ID
- Course Name
- Credits

### Features
- Add Courses
- View Courses
- Update Course Details
- Delete Courses

---

## 🔗 Enrollments Module
Links students and courses using foreign keys.

### Features
- Enroll Students into Courses
- Manage Student-Course Relationships
- Demonstrate SQL Relational Joins
- Maintain Referential Integrity

---

# 🗄️ Database Design

The database consists of three interconnected tables:

## 1️⃣ Students Table
Stores student information such as:
- Student ID
- Name
- Age
- Department

---

## 2️⃣ Courses Table
Contains course-related details:
- Course ID
- Course Name
- Credits

---

## 3️⃣ Enrollments Table
Acts as a bridge between Students and Courses using:
- Student ID (Foreign Key)
- Course ID (Foreign Key)

### Database Features
- Primary Keys
- Foreign Keys
- Relational Joins
- Referential Integrity
- Structured Data Management
